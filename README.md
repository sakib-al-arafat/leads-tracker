# Leads Tracker

A simple Chrome extension that helps you save and keep track of interesting URLs while browsing the web.

## Features

- **Save Input:** Manually enter and save URLs.
- **Save Tab:** Quickly save the URL of your currently active browser tab.
- **Persistent Storage:** Automatically saves your leads using the browser's `localStorage`, so they remain available after closing the popup or browser.
- **Open Links:** Click on any saved URL to open it in a new tab.
- **Delete All:** Clear all saved leads with a double-click.

## Built With

- HTML5
- CSS3
- JavaScript
- Chrome Extensions API (Manifest V3)
- Local Storage

## Installation

This extension is not currently published on the Chrome Web Store. You can install it manually using Chrome's Developer Mode.

1. Clone this repository:

   ```bash
   git clone https://github.com/sakib-al-arafat/leads-tracker.git
   ```

2. Open Google Chrome and navigate to:

   ```text
   chrome://extensions
   ```

3. Enable **Developer mode** in the top-right corner.

4. Click **Load unpacked**.

5. Select the cloned `leads-tracker` folder.

6. The Leads Tracker extension should now appear in your Chrome extensions list!

## How to Use

1. Click the Leads Tracker icon in your Chrome toolbar.
2. Enter a URL in the input field and click **SAVE INPUT**, or navigate to a website and click **SAVE TAB** to save its URL.
3. Click any saved link to open it in a new tab.
4. Double-click **DELETE ALL** to remove all saved leads.
